# جرد الأصل وخطة الإكمال

ابدأ بـ[مقارنة الميزات](comparison-ar.md)، ثم [خريطة الواجهات](screen-map.md) و[خطة التنفيذ](implementation-plan.md). افتح `index.html` محليًا لبحث تفاعلي في الميزات والوجهات والأزرار؛ GitHub يعرض مصدر HTML ولا يشغله.

الأولوية المحدثة: [خطة الدفعة التالية](next-batch.md) لتصحيح التدرج والمنظور على النص وإضافة إنشاء الأنماط وإدارتها. الحالة الحالية خطة، وليست إصلاحًا منفذًا. سياسة المجانية تخص أدوات Cookies المحلية ولا تغيّر رصيد الخادم الأصلي.

## إعادة التوليد

من جذر المستودع، بعد توفير مجلد مرجع APK المفكك محليًا:

```sh
python3 scripts/audit_reference_inventory.py /path/to/ytyper-v45-reference
python3 scripts/build_parity_matrix.py
python3 scripts/build_parity_report.py
```

الفهرس الآلي يقرأ XML والإشارات البرمجية. المصفوفة وخريطة الوجهات مراجعة يدوية مثبتة على iOS `25d6f9f` وAPK 4.5 وليستا اكتشافًا آليًا لغياب الوظائف. تحديث الكود لا يحدّث الحالة تلقائيًا؛ يلزم تحديث الأدلة والمصفوفة معًا.

واجهات الأصل المصادقة والميزات المشروطة بالخدمة، وأزرار Compose المنشأة ديناميكيًا، تحتاج سيناريوهات تشغيل إضافية. لا تُحسب موردة مخفية أو نافذة لم تُفتح كميزة مجربة. لقطات الأصل المتاحة تشمل البداية والمشاريع والعمل والإعدادات والمحرر والنص والمقابض والطبقات؛ زر المكافآت ليس زر المجتمع.

لم يتغير كود التطبيق في هذه دفعة الجرد. اختبارات آخر IPA ناجحة على iPhone، وفي iPad فشل اختبار جاهزية cache واحد؛ موثق في خطة المرحلة 0. لا توجد نسبة اكتمال أو دعوى مطابقة بصرية كاملة.
